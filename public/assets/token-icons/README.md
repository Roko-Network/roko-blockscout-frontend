# ROKO testnet token artwork

`token-list.json` is the canonical public metadata feed for the ROKO testnet
Blockscout deployment. It follows the Token Lists schema consumed by
Blockscout's `TOKEN_LIST_URL` fetcher.

- Native ROKO continues to use `/assets/configs/network_icon.png`.
- pwROKO uses `pwroko.svg`.
- CATBOT and its legacy test deployment use the canonical supplied
  `catbot.jpg` brand image.
- Clowder CATBOT/ROKO liquidity-token deployments share
  `clowder-cat-roko-lp.svg`.

Keep addresses checksummed and increment the semantic version whenever entries
or artwork URLs change.
