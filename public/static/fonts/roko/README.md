# ROKO font assets

- Rajdhani weights 300–700 are sourced from the Google Fonts Rajdhani family.
- JetBrains Mono is sourced from the Google Fonts JetBrains Mono family.

Both families are distributed under the SIL Open Font License 1.1. Their font
files are hosted locally so the explorer has deterministic typography and makes
no runtime request to a font CDN.
